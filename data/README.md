# Data

The raw MRI images are not stored in this repository (about 150 MB). The notebook downloads them automatically with `kagglehub`.

- **Dataset:** Brain Tumor MRI Dataset by Masoud Nickparvar (version 2)
- **Link:** https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset
- **License:** CC0: Public Domain

`split_manifest.csv` lists every image kept after duplicate removal, with its class and its split (train / validation / test), so the exact split can be reproduced.
