# Data



The raw MRI images are not stored in this repository (about 150 MB).



\- \*\*Dataset:\*\* Brain Tumor MRI Dataset by Masoud Nickparvar

\- \*\*Link:\*\* https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

\- \*\*License:\*\* CC0: Public Domain

\- \*\*Get it on Kaggle:\*\* in the notebook editor, Add Input → search "Brain Tumor MRI Dataset" → Add



This folder will hold `split\_manifest.csv`: every image with its class and its train / validation / test split, so the exact split can be reproduced.
